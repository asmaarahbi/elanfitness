# Elan Fitness

## Presentation

Elan fitness est un site web pour une salle de sport a Casablanca. Il presente les programmes sportifs, la salle de sport et les informations de contact.

## Technologies utilisees

* HTML5
* CSS3
* Git et GitHub

## Outil de planification

Nous avons utilise Trello pour organiser les taches, planifier les etapes du projet et suivre notre progression.

## Pages du site

* Accueil
* Programmes
* A propos
* Contact

## Fonctionnalites

* Navigation entre les differentes pages
* Design simple et coherent
* Adaptation aux differents ecrans (responsive design)

## Problemes rencontres

J'ai rencontre quelques difficultes dans le style CSS et l'adaptation du site aux ecrans de telephone. J'ai travaille sur la mise en page et le responsive design pour ameliorer l'affichage.
